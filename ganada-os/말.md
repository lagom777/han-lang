# 가나다 — 말

숫자와 기호에서 출발한 언어. C가 아니다. C도 없다.

```
1  숫자     0 1 2   명령 번호 4, 14, 15
2  기호     + - * / = == != < > { } ( ) " #
3  이름     만약 아니면 동안 출력   ← 여기만 한글
```

값은 정수 하나다. 참은 `1`, 거짓은 `0`. 타입 키워드 없다.
이름은 한글만. `x` `tmp` 는 묶지 않는다.

## 되는 것

```가나다
가 = 40
나 = 2
출력(가 + 나)
출력(가 * 2 + 1)

이 = 1
동안 이 < 6 {
    출력(이)
    이 = 이 + 1
}

만약 가 < 0 {
    출력("음")
}
아니면 만약 가 == 0 {
    출력("영")
}
아니면 {
    출력(가)
}
```

`*` `/` 가 `+` `-` 보다 먼저. 비교는 그 다음. `(` `)` 로 묶는다.
`-3` 은 `0-3` 이다.

## 안 되는 것 (아직 · 핵에 안 넣음)

묶음(부르기), 목록, 사전, 람다, 서버, 질문, `정수` 타입, 영어 이름.
그건 옛 실험(`ganada-c`)이거나 다음 숫자다.

## 길

```
한글 .ㄱㄴㄷ  →  묶기  →  .ㄱㅂ 숫자  →  가상  →  기계
```

지금은 `사다리/묶기`가 호스트 파이썬이다. `컴파일러/*.ㄱㄴㄷ`가
열기·읽기·쓰기를 갖게 되면 사다리를 지운다.
시드는 어셈블리다. 어셈은 C가 아니라 숫자다.
