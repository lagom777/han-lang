# 가나다 — 말

숫자와 기호에서 출발한 언어. C가 아니다. C도 없다.

```
1  숫자     0 1 2   명령 번호 4, 18, 19
2  기호     + - * / % = == != < > { } ( ) " # ,
3  이름     만약 아니면 동안 출력 묶음 돌려주기 열기 만들기 읽기 쓰기 닫기
```

값은 정수 하나다. 참은 `1`, 거짓은 `0`. 타입 키워드 없다.
이름은 한글만. `x` `tmp` 는 묶지 않는다.
칸은 묶음마다 32개. 부르면 새 막.

## 되는 것

```가나다
이 = 0
합 = 0
동안 이 < 11 {
    합 += 이
    이 += 1
}
출력(합)
출력(10 % 3)

묶음 피보(수) {
    만약 수 < 2 {
        돌려주기 수
    }
    돌려주기 피보(수 - 1) + 피보(수 - 2)
}
출력(피보(10))

내기 = 만들기("산출/낸글")
쓰기(내기, 66)
닫기(내기)
```

`*` `/` `%` 가 `+` `-` 보다 먼저. 비교는 그 다음. `( )` 로 묶는다.
`+=` `-=` `*=` `/=` `%=` 는 기호 단축.

## 안 되는 것

목록, 사전, 람다, 서버, 질문, `정수` 타입, 영어 이름.
그건 옛 실험(`ganada-c`)이다.

## 길

```
한글 .ㄱㄴㄷ  →  묶기  →  .ㄱㅂ 숫자  →  가상  →  기계
```

지금은 `사다리/묶기`가 호스트 파이썬이다. 열기·읽기·쓰기가 열렸으니
`컴파일러/*.ㄱㄴㄷ`가 사다리를 대신할 수 있다.
시드는 어셈블리다. 점프표로 명령을 보낸다. 어셈은 C가 아니라 숫자다.
