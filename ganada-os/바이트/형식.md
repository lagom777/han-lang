# 가나다 바이트열 (`.ㄱㅂ`)

숫자와 기호가 먼저다. 한글은 그 숫자의 이름이다.
리틀엔디안 스택 기계. 참은 `1`, 거짓은 `0`.

| 번호 | 이름 | 기호·쓰임 | 인자 | 동작 |
|------|------|-----------|------|------|
| 0 | 끝 | | — | 멈춤 |
| 1 | 정수넣기 | `3` | i64 | 숫자 올리기 |
| 2 | 정수쓰기 | `출력(수)` | — | 팝, 십진, 줄바꿈 |
| 3 | 글쓰기 | `출력("글")` | u32길이+바이트 | 글 찍고 줄바꿈 |
| 4 | 더하기 | `+` | — | |
| 5 | 빼기 | `-` | — | |
| 6 | 곱하기 | `*` | — | |
| 7 | 나누기 | `/` | — | |
| 8 | 복제 | | — | 꼭대기 하나 더 |
| 9 | 버림 | | — | 꼭대기 버리기 |
| 10 | 점프 | | i32상대 | |
| 11 | 영이면점프 | `만약` `동안` | i32상대 | 팝 후 0이면 가기 |
| 12 | 꺼내기 | 이름 | u8칸 | 칸 → 스택 |
| 13 | 넣기 | `=` | u8칸 | 스택 → 칸 |
| 14 | 같다 | `==` | — | 같으면 1 |
| 15 | 작다 | `<` | — | 작으면 1 |
| 16 | 크다 | `>` | — | 크면 1 |
| 17 | 아니다 | `!=` `<=` `>=` 에 씀 | — | 0이면 1, 아니면 0 |

`!=` 는 같다+아니다. `<=` 는 크다+아니다. `>=` 는 작다+아니다.

파일: **`.ㄱㅂ`**. 실행기: **`가상`**. 소스: **`.ㄱㄴㄷ`**.
