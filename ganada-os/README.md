# 가나다 (숫자 시드 → 한글만)

**영어 이름·영어 확장자 안 씀.**

| 역할 | 이름 |
|------|------|
| 소스 | `*.ㄱㄴㄷ` |
| 바이트열 | `*.ㄱㅂ` |
| 기대 출력 | `*.기대` |
| 실행기 | `가상` |
| 시드 | `시드/가상.s` (어셈블리·숫자 층) |
| 임시 묶기 | `사다리/묶기` (셀프호스트 후 삭제) |
| 정본 컴파일러(목표) | `컴파일러/*.ㄱㄴㄷ` |

```
한글 .ㄱㄴㄷ  →  (.ㄱㅂ 숫자)  →  가상(시드)  →  CPU
```

## 검사

```bash
cd ganada-os
make 검사
```

## 폴더

- `시드/` — C 없는 가상 기계  
- `사다리/` — 임시 묶기(호스트 파이썬, 삭제 예정)  
- `검사/` — 골든 테스트  
- `컴파일러/` — 한글 정본 컴파일러 자리  
- `바이트/형식.md` — 숫자 명령 표  
- `산출/` — 생성물  

`../ganada-c` 는 레거시. 여기 정본과 무관.
