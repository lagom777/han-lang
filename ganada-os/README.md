# 가나다 (숫자·기호 → 한글 이름)

C가 아니다. 파이썬이 아니다. **숫자와 기호에서 출발**한다.
영어 이름·영어 확장자 안 씀. 묶기도 가나다가 한다.

| 역할 | 이름 |
|------|------|
| 소스 | `*.ㄱㄴㄷ` |
| 바이트열 | `*.ㄱㅂ` |
| 기대 출력 | `*.기대` |
| 실행기 | `가상` |
| 시드 | `시드/가상.s`(맥) · `시드/리눅스.s` |
| 정본 묶기 | `컴파일러/첫묶기.ㄱㄴㄷ` + `컴파일러/첫묶기.ㄱㅂ` |
| 말 | `말.md` |

```
한글 .ㄱㄴㄷ  →  첫묶기.ㄱㅂ  →  .ㄱㅂ 숫자  →  가상  →  CPU
```

## 검사

```bash
cd ganada-os
make 검사
```

파이썬을 부르지 않는다. 정본 묶기가 검사를 묶고, 가상이 실행한다.
`make 다시묶기` 는 첫묶기가 자기 소스를 다시 낳는다.
