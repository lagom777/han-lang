# 가나다 OS · 가나다 언어 (C 없는 정본 경로)

**목표:** C로 구현한 인터프리터가 아니라, **가나다 바이트코드 VM + (장기) 가나다로 짠 OS**.  
**리눅스 사용자공간 셸 ≠ OS.** 베어메탈/QEMU 게스트가 목표. 지금은 **호스트에서 VM만** 검증.

## 빠른 검증

```bash
cd ganada-os
make test
```

- `kernel/vm_host.s` — **어셈블리만** (C 소스 0)  
- `bootstrap/gbcpack.py` — **일시 부트스트랩** (셀프호스트 후 삭제)  
- `tests/*.ㄱㄴㄷ` → `.gbc` → `gvm` 실행 → 골든 diff  

## 레이아웃

| 경로 | 역할 |
|------|------|
| `kernel/` | VM·(나중) 부팅 코드 — 어셈블리 |
| `bc/` | 바이트코드 포맷 |
| `bootstrap/` | 임시 컴파일러 |
| `tests/` | 골든 테스트 |
| `../plan/ganada-os.md` | 전체 계획 |
