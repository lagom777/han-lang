# 가나다 (숫자·기호 → 한글 이름 → 기계어)

C가 아니다. 파이썬이 아니다. **숫자와 기호에서 출발**한다.
한글은 이름이다. 낳기가 그 숫자를 CPU가 먹는 기계어로 바꾼다.

C의 뿌리(정수, 기호, 직접 기계)를 지키면서 C가 버린 것을 넣었다.

| C가 버린 것 | 가나다 |
|---|---|
| 배열은 길이 없는 포인터 | `열만들기` — 길이가 앞에 있다. 넘치면 트랩 |
| `&& \|\|` 영어, 0/1만 | `그리고` `또는` — 단락, 값 그대로 |
| `flags & MASK == 0` 함정 | 비트가 비교보다 먼저 |
| `/0`, 집 넘침, 덧셈 넘침은 정의 없음 | 기계가 멈춘다 |
| `for (i=1;i<=n;i++)` 끝 열림 | `각각 이 1..n` 닫힌 범위 |

| 역할 | 이름 |
|------|------|
| 소스 | `*.ㄱㄴㄷ` |
| 숫자열 (IR) | `*.ㄱㅂ` |
| 기대 출력 | `*.기대` |
| 낳는 손 | `낳기` |
| 실행 | 낳은 ELF (CPU) |
| 시드 | `시드/뼈.s` · `시드/낳기.s` · `시드/리눅스.s`(디버그) |
| 정본 묶기 | `컴파일러/첫묶기.ㄱㄴㄷ` + `컴파일러/첫묶기.ㄱㅂ` |
| 말 | `말.md` |

```
한글 .ㄱㄴㄷ  →  첫묶기 ELF  →  .ㄱㅂ 숫자  →  낳기  →  기계어 ELF  →  CPU
```

## 검사

```bash
cd ganada-os
make 검사
```

파이썬을 부르지 않는다. 가상을 부르지 않는다.
정본 묶기가 검사를 묶고, 낳기가 기계어를 낳고, CPU가 실행한다.
`make 다시묶기` 는 첫묶기가 자기 소스를 다시 낳는다.

## 지금 되는 말

대입 `=` `+=` · 셈 `+ - * / %` · 비교 `== != < > <= >=` ·
비트 `& | ^ ~ << >>` · 단락 `그리고` `또는` ·
`만약`/`아니면`/`동안`/`멈춤`/`계속` · `묶음`/`돌려주기` ·
열 `열만들기` `열읽기` `열쓰기` `열길이` · `각각` · 범위 `1..n` ·
파일·집·인수. 이름은 한글만. 값은 부호 있는 64비트다.
한 인자 묶음은 레지스터로 부른다. 재귀 덧셈은 값 칸을 건너뛴다.
