# 가나다 (숫자·기호 → 한글 이름)

C가 아니다. 자연어도 아니다. **숫자와 기호에서 출발**한다.
영어 이름·영어 확장자 안 씀.

| 역할 | 이름 |
|------|------|
| 소스 | `*.ㄱㄴㄷ` |
| 바이트열 | `*.ㄱㅂ` |
| 기대 출력 | `*.기대` |
| 실행기 | `가상` |
| 시드 | `시드/가상.s`(맥) · `시드/리눅스.s` |
| 임시 묶기 | `사다리/묶기` (셀프호스트 후 삭제) |
| 정본 컴파일러(목표) | `컴파일러/*.ㄱㄴㄷ` |
| 말 | `말.md` |

```
한글 .ㄱㄴㄷ  →  (.ㄱㅂ 숫자)  →  가상(시드)  →  CPU
```

## 검사

```bash
cd ganada-os
make 검사
```

맥(팔64)과 리눅스(x86_64) 시드가 같은 숫자를 실행한다.
가상은 점프표·스택 인라인. `동안` 만 번 합이 밀리초 안이다.

## 지금 되는 말

대입 `=` `+=` · 셈 `+ - * / %` · 비교 `== != < > <= >=` ·
`만약`/`아니면`/`동안` · `묶음`/`돌려주기` · `열기`/`만들기`/`읽기`/`쓰기`/`닫기`.
이름은 한글만. 자세한 것은 `말.md`, 숫자는 `바이트/형식.md`.

- `바이트/형식.md` — 숫자 명령 표
