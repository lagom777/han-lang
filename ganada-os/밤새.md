# 가나다 밤새 고도화

한 바퀴에 **하나**만. 겉(문장·색·주석) 금지. 깊게(낳기·첫묶기·말).

## 절대

- `컴파일러/첫묶기.ㄱㄴㄷ` 은 **StrReplace만**. Write/덮어쓰기 금지. 한 번 깨졌다.
- 한글만 소스. 영어 키워드 금지. 가상 해석기로 검사하지 말 것.
- 검사: `cd /workspace/ganada-os && make 검사` 그리고 `make 다시묶기`.
- 미리보기 `0.0.0.0:8080` / `startup.sh` 유지.
- 새 말은 옛 묶기로 컴파일되게(컴파일러 소스는 옛 언어만).

## 한 바퀴

1. 이 파일의 **남음** 맨 위를 고른다. 이미 **됨**이면 다음.
2. 깊게 구현. 검사·자기묶기.
3. 속도가 바뀌면 피보30·합천만 다시 재고 `src/routes/index.tsx` SPEED_ROWS.
4. 말이 바뀌면 `말.md` · 스튜디오 기둥 · `검사.json`.
5. 이 파일 **됨**에 한 줄, **남음**에서 지운다. 실패면 **막힘**에 원인.

## 됨

- 열 길이·범위 트랩, 그리고/또는 단락, 비트 우선, 각각, 글열, `1..n` 닫힌 범위
- 한 인자 얇은 부르기(rdi/r9/rax), 피보 `f(n-1)+f(n-2)` 레지스터 붙임
- 더하기·빼기·곱 넘침 트랩
- 검사 23 + 넘침 함정. 피보30 ≈5.4ms, 합천만 ≈7ms
- **리터럴 64비트** — 수읽기/수쓰기 8바이트 부호. `9223372036854775807` 그대로. `아니면` 보초는 -1 대신 2000000000 (32비트 감쌈 함정)

## 남음 (위가 먼저)

1. **피보 vs C-O2** — 5.4ms vs 2.4ms. 잎 `cmp r9, imm8`, TOS를 rax에, 넘침 `jo`는 핫 재귀에 두되 예측 실패 줄이기. C를 베끼지 말고 가나다 규약으로 좁히기.
2. **두 인자 레지스터** — `수쓰기(곳,값)` 같은 둘도 메모리 칸을 덜 쓰게.
3. **상수 접기** — `1+2*3` 을 묶을 때 숫자로. 첫묶기 자신이 빨라진다.
4. **열자르기** — `열자르기(가, 시작, 끝)` 길이 있는 보기. C 포인터 산수가 버린 것.
5. **가상 ops 31–40** — 검사 경로는 아님. `시드/리눅스.s` 디버그만 맞추기. 우선순위 낮음.
