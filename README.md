# 한 (Han)

한글로 코딩하는 **독립 프로그래밍 언어**. AI 개발에 최적화하는 것을 목표로 한다.

> 파이썬으로 트랜스파일하지 않는다. 자체 문법 + 자체 렉서·파서·트리워킹 인터프리터로 직접 실행한다.
> (구현 호스트가 파이썬일 뿐, 언어 자체는 독립적 — CPython이 C로 구현됐다고 파이썬이 C가 아니듯.)

## 실행
```bash
python3 han.py 실행 examples/hello.han   # 파일 실행
python3 han.py 대화                       # 대화형(REPL)
python3 tests/test_han.py                 # 테스트
```

## 맛보기
```han
함수 피보나치(수) {
    만약 수 < 2 { 반환 수 }
    반환 피보나치(수 - 1) + 피보나치(수 - 2)
}
반복 i 를 0 부터 10 까지 {
    출력("피보나치(" + i + ") = " + 피보나치(i))
}
```

## v0 문법
- 변수: `이름 = 값`
- 함수: `함수 이름(매개변수) { ... 반환 값 }`
- 조건: `만약 조건 { ... } 아니면 만약 조건 { ... } 아니면 { ... }`
- 반복: `반복 i 를 0 부터 5 까지 { ... }` (양끝 포함), `동안 조건 { ... }`
- 값: 정수·실수·문자열·`참`/`거짓`/`없음`
- 연산: `+ - * / %`, `== != < <= > >=`, `그리고`/`또는`/`아니다`
- 내장: `출력(...)`, `길이(...)`, `숫자(...)`
- 주석: `# ...`
