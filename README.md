# 가나다

한글로 코딩하는 **독립 프로그래밍 언어**. AI 개발에 최적화하는 것을 목표로 한다.

> 파이썬으로 트랜스파일하지 않는다. 자체 문법 + 자체 렉서·파서·트리워킹 인터프리터(`가나다.py`)로 직접 실행한다.
> (구현 호스트가 파이썬일 뿐, 언어 자체는 독립적 — CPython이 C로 구현됐다고 파이썬이 C가 아니듯.)

## 실행
```bash
python3 가나다.py 실행 examples/hello.ㄱㄴㄷ   # 파일 실행
python3 가나다.py 대화                       # 대화형(REPL) — 여러 줄 블록 OK, 식은 값이 바로 나옴 (방향키로 이전 입력 불러오기, `:기록` 으로 입력 목록, `:도움` 명령, `:종료` 끝내기)
python3 tests/test_han.py                 # 테스트
```

## 맛보기
```가나다
함수 피보나치(수) {
    만약 수 < 2 { 반환 수 }
    반환 피보나치(수 - 1) + 피보나치(수 - 2)
}
반복 i 를 0 부터 10 까지 {
    출력("피보나치(" + i + ") = " + 피보나치(i))

```

## 문법

**변수 / 복합 대입**
```가나다
이름 = "한"
합 = 0
합 += 5      # -= *= /= 도 됨 (변수·목록인덱스·문자열)
가, 나 = [1, 2]    # 구조 분해 대입 (목록/쌍을 한 번에)
```

**함수 / 람다(익명 함수)**
```가나다
함수 더하기(가, 나) { 반환 가 + 나 }
함수 인사(이름, 말="안녕") { 반환 말 + ", " + 이름 }   # 기본 인자(뒤쪽만)
제곱 = 람다(x) { 반환 x * x }     # 일급 함수 → 고차함수 가능
```

**조건**
```가나다
만약 점수 >= 90 { 출력("상") }
아니면 만약 점수 >= 70 { 출력("중") }
아니면 { 출력("하") }
```

**고르기** (지연 조건 선택 · 삼항 조건식 대용) — `고르기(조건, 참값, 거짓값)`: 조건이 참이면 `참값`, 아니면 `거짓값`. **선택된 가지만 평가**(지연)라 안 쓰는 가지의 오류(0 나누기 등)는 실행 안 됨. 후위 `만약` 삼항은 일부러 미지원이라 이걸로 대신. → `examples/choose.ㄱㄴㄷ`
```가나다
등급 = 고르기(점수 >= 90, "A", "B")           # 삼항 대용
출력(고르기(수 != 0, 100 / 수, "정의 안 됨"))    # 지연: 수=0이면 100/수 실행 안 함
```

**반복** (양끝 포함 범위 / 컬렉션 순회 / while), **멈춤·계속**
```가나다
반복 i 를 1 부터 5 까지 { 출력(i) }
반복 과일 를 ["사과", "배"] 에서 { 출력(과일) }
반복 i, 과일 를 ["사과", "배"] 에서 { 출력(i + ": " + 과일) }   # 순회 인덱스
동안 수 > 0 { 수 -= 1 }
반복 i 를 1 부터 100 까지 {
    만약 i % 2 == 0 { 계속 }
    만약 i > 9 { 멈춤 }
}
```

**자료형**: 정수·실수·문자열·`참`/`거짓`/`없음`·목록 `[..]`·사전 `{키:값}`
```가나다
목록 = [1, 2, 3]
목록[0] = 9
사람 = {"이름": "한", "나이": 1}
사람["나이"] += 1
```

**모듈**
```가나다
가져오기 "lib.ㄱㄴㄷ"          # 다른 .ㄱㄴㄷ 파일의 함수·변수를 현재 환경에 플랫 주입
수학 = 모듈("lib.ㄱㄴㄷ")     # 격리 네임스페이스 사전 — 수학["제곱"](5) → [앱 구조](#앱-구조-여러-파일) 참고
```

**연산**: `+ - * / %`, `== != < <= > >=`, `그리고`/`또는`/`아니다`
**주석**: `# ...`

## 내장 함수
- **출력·입력**: `출력(...)`, `입력([프롬프트])`, `숫자(문자열)`, `타입(값)`
- **파일**: `파일읽기(경로)` → 내용, `파일쓰기(경로, 내용)`(덮어씀) → 쓴 글자 수, `이어쓰기(경로, 내용)`(끝에 덧붙임·로그), `파일존재(경로)` → 참/거짓, `파일목록(경로)` → 디렉터리 항목 목록(정렬) (UTF-8; 오류는 시도/잡기로)
- **환경**: `환경변수(이름[, 기본값])` → 값 또는 기본값 (설정·비밀키)
- **모듈**: `모듈(경로)` → 파일을 격리 실행해 최상위 함수·변수를 네임스페이스 사전으로 반환(경로별 캐시 — 같은 경로는 같은 사전·상태 공유) → **[앱 구조](#앱-구조-여러-파일)** 참고
- **시간**: `지금()` → 현재 유닉스 시각(초, 소수) — 타임스탬프·경과 측정
- **목록**: `길이` `추가` `합` `평균` `중앙값` `최빈값` `표준편차` `정렬` `상위(목록,개수)`(top-N) `최대` `최소` `범위(끝|시작,끝|시작,끝,간격)` `간격(시작,끝,개수)`(linspace 균등분할) `거꾸로` `고유` `개수(목록,값)` `빈도(목록)`(원소별 개수→사전) `묶기(목록1,목록2)`(zip) `묶음(목록,크기)`(chunk) `평탄화(목록)`(flatten 1단계) `누적합(목록)`(running total) `회전(목록,칸수)`(왼쪽 회전, 음수면 오른쪽) `전치(2차원목록)`(transpose) `정규화(목록)`(min-max 0~1) · 고차: `생성(개수,함수)`(Array.from) `변환`(map) `거르기`(filter) `분할(목록,함수)`(partition→[참,거짓]) `그룹화(목록,키함수)`(groupby→{키:[원소들]}) `접기(목록,초기값,함수)`(reduce) `정렬기준(목록,키함수)` `상위기준(목록,개수,키함수)`(키 기준 top-N) `최대기준(목록,키함수)`(argmax) `최소기준`(argmin) `찾기`(find) `있나`(any) `모두`(all) · 집합: `교집합` `합집합` `차집합`
- **문자열**: `대문자` `소문자` `다듬기` `말줄임(문자열,최대길이)`(…) `바꾸기` `나누기` `합치기` `포함` `시작` `끝` `위치(문자열,부분)` `서식(틀,…값)` `왼쪽채우기(값,너비[,채움])` `오른쪽채우기(값,너비[,채움])`
- **사전**: `키들` `값들` `항목들` `사전만들기(키목록,값목록)`(zip→사전) `병합(사전들…)` `값얻기(사전,키[,기본])` `키있나(사전,키)`
- **JSON**: `제이슨파싱(문자열)` → 값 · `제이슨문자열(값[, 들여쓰기])` → JSON 문자열
- **수학**: `절댓값` `반올림(수[,자리])`(5는 올림·사사오입) `올림` `내림` `제곱근` `거듭제곱(밑,지수)` `천단위(수)`(콤마 표기) `사이값(값,최소,최대)`(clamp) `최대공약수(가,나)` `최소공배수(가,나)`
- **무작위**: `무작위()`(0~1) `무작위정수(시작,끝)` `무작위선택(목록)`
- **AI**: `모델([이름])`(기본 LLM 설정/조회) · `질문(프롬프트[, 모델])` · `체계질문(시스템, 사용자[, 모델])` · `분류(텍스트, 보기목록[, 모델])`(LLM 분류) — OpenRouter LLM 호출 (`OPENROUTER_API_KEY` 필요, 없으면 안내)
- **웹**: `서버(포트, 라우트[, 정적폴더])` — 라우트 `{경로:함수}` 로 HTTP 서비스(블로킹). 각 함수는 요청 `{메서드,경로,질의,본문,쿠키}` 를 받아 문자열(→200 text/html) 또는 `{상태,헤더,본문[,쿠키설정]}` 을 반환. 없는 경로는 404. 파이썬 표준 라이브러리만 사용(외부 의존성 0) → **[웹 배포](#웹-배포)** 참고
- **자료(SQLite)**: `자료열기(경로)` → 핸들(`":memory:"` 는 메모리 전용) · `실행(핸들, SQL[, 인자목록])` → 변경 행 수(문장마다 자동 커밋; CREATE 등은 0) · `질의(핸들, SQL[, 인자목록])` → 행 목록(각 행은 `{컬럼명:값}` 사전) · `자료닫기(핸들)`. 값 끼워넣기는 문자열 잇기 대신 **`?` 자리표시자 + 인자목록**(SQL 주입 방지). 한글 테이블·컬럼명 OK. 트랜잭션은 `거래(핸들, 함수)` — 함수 안의 여러 작업을 하나로 묶어 성공하면 커밋, 오류가 나면 전부 롤백(자료열기·저장소 핸들 모두 가능). 예제: `examples/자료.ㄱㄴㄷ`(방명록)·`examples/거래.ㄱㄴㄷ`(계좌 이체)
- **저장소(SQL 없는 DB)**: `저장소(경로, 이름)` → 저장소 · `넣기(저장소, 사전)` → 번호 · `모두(저장소)` → 기록 목록(각 사전에 `"번호"`) · `찾기(저장소, 조건사전)` → 조건 키=값 전부 일치하는 기록 목록 · `고치기(저장소, 번호, 사전)`(부분 수정)/`빼기(저장소, 번호)` → 성공여부 → **[한 몸 풀스택](#한-몸-풀스택)** 참고
- **HTML 도우미(HTML 없는 화면)**: `문서(제목, ...본문조각)` → 완성 페이지 · `글(텍스트[, 크기1~3])`(문단/제목) · `목록(문자열목록)`(점 목록) · `연결(주소, 텍스트)`(링크) · `입력폼(주소, 필드이름목록[, 버튼텍스트])`(입력 폼). 일반 문자열은 자동 이스케이프(XSS 차단), 도우미가 만든 조각은 그대로 통과

## 오류 처리
- `시도 { } 잡기(오류) { }` 로 잡고, `발생("메시지")` 로 직접 던진다.
- 구문/렉서 오류엔 **행+열** — 예: `[1행 7열] 구문 오류: 예기치 않은 ')'`
- 런타임 오류엔 행 번호 — 예: `[2행] 이름 오류: '없는변수' 가 정의되지 않았습니다`
- 변수 오타엔 비슷한 이름 제안 — 예: `이름 오류: '점수몰록' ... (혹시 '점수목록'?)`
- 사전 키 오타엔 비슷한 키 제안 / 없으면 키 목록 — 예: `키 없음: 최고점쑤 (혹시 '최고점수'?)`

## 한 몸 풀스택
**프론트·백엔드·디비를 한 언어로 한 번에** — SQL도 HTML도 몰라도, 가나다 개념(사전·목록·함수)만으로 풀스택 앱을 만든다.

- **디비**: `저장소(경로, 이름)` 로 열고 `넣기`/`모두`/`찾기`/`고치기`/`빼기` 로 사전을 그대로 저장·조회 (SQL 0줄 — 내부는 SQLite)
- **화면**: `문서`/`글`/`목록`/`연결`/`입력폼` 으로 조립 (HTML 0줄 — 사용자 입력은 자동 이스케이프라 XSS 안전)
- **서버**: `서버(포트, 라우트)` 하나로 서비스

완성 방명록 앱 전체(`examples/한몸.ㄱㄴㄷ`) — 이게 전부다:
```가나다
방명록 = 저장소("방명록.db", "글들")

함수 첫화면(요청) {
    글들 = 모두(방명록)
    줄들 = []
    반복 항목 를 글들 에서 { 추가(줄들, 항목["이름"] + ": " + 항목["내용"]) }
    반환 문서("방명록",
        글("방명록", 1),
        글("지금까지 " + 길이(글들) + "개의 글이 있어요."),
        목록(줄들),
        글("새 글 남기기", 2),
        입력폼("/등록", ["이름", "내용"], "남기기"))
}

함수 등록(요청) {
    이름 = 값얻기(요청["질의"], "이름", "익명")
    번호 = 넣기(방명록, {"이름": 이름, "내용": 값얻기(요청["질의"], "내용", "")})
    반환 문서("등록 완료",
        글(이름 + " 님의 글이 " + 번호 + "번으로 저장됐어요."),
        연결("/", "방명록으로 돌아가기"))
}

서버(8000, {"/": 첫화면, "/등록": 등록})
```
```bash
python3 가나다.py 실행 examples/한몸.ㄱㄴㄷ   # → http://localhost:8000 (등록하면 목록에 바로 반영)
```
직접 SQL·태그가 필요해지면 언제든 `자료열기`/`실행`/`질의` 와 문자열 HTML 로 내려갈 수 있다(같은 서버에 섞어 써도 됨).

## 앱 구조 (여러 파일)
파일 하나 = 앱 하나로는 관리가 안 된다. 파일은 전부 확장자 `.ㄱㄴㄷ`, **폴더 하나 = 앱 하나** — 관심사별 세 파일 컨벤션:

- `자료.ㄱㄴㄷ` — 저장소 열기 + 넣기/모두를 감싼 함수 (데이터만 안다)
- `화면.ㄱㄴㄷ` — 문서/글/목록/입력폼 조합 함수 (보여주기만 안다)
- `앱.ㄱㄴㄷ` — 모듈 둘을 불러 라우트 정의 + `서버()` (엮기만 한다)

**모듈() vs 가져오기** — 사용 구분:
- `모듈("경로")` → 격리 네임스페이스 사전. 앱 구조용 — 이름 충돌 없음: `자료 = 모듈("자료.ㄱㄴㄷ")` 후 `자료["글모두"]()`
- `가져오기 "경로"` → 현재 환경에 플랫 주입. 작은 도우미 모음을 이름 그대로 쓰고 싶을 때

완성 앱(`examples/방명록앱/`)의 `앱.ㄱㄴㄷ` 전체 — 엮는 파일은 이만큼이면 된다:
```가나다
자료 = 모듈("자료.ㄱㄴㄷ")
화면 = 모듈("화면.ㄱㄴㄷ")

함수 첫화면(요청) { 반환 화면["방명록화면"](자료["글모두"]()) }

함수 등록(요청) {
    이름 = 값얻기(요청["질의"], "이름", "익명")
    번호 = 자료["글넣기"](이름, 값얻기(요청["질의"], "내용", ""))
    반환 화면["등록화면"](이름, 번호)
}

서버(숫자(환경변수("포트", "8000")), {"/": 첫화면, "/등록": 등록})
```
```bash
python3 가나다.py 실행 examples/방명록앱/앱.ㄱㄴㄷ   # → http://localhost:8000
```
같은 경로의 `모듈()` 은 인터프리터당 한 번만 실행되고 같은 사전을 돌려준다(캐시) — 어느 파일에서 불러도 같은 저장소·상태를 공유한다. 포트는 `환경변수("포트", "8000")` 로 읽어 배포·테스트 때 주입할 수 있다.

## 웹 배포
가나다로 웹 앱을 만들고 Docker로 어디든 배포할 수 있어요. 서버는 파이썬 표준 라이브러리로만 돌아가서 **외부 의존성이 0** 입니다.

**만들기** — `서버(포트, 라우트)` 하나면 끝. 라우트는 `{경로: 함수}` 사전:
```가나다
함수 홈(요청) { 반환 "<h1>안녕, 가나다 웹!</h1>" }
함수 인사(요청) { 반환 "이름: " + 값얻기(요청["질의"], "이름", "손님") }
서버(8000, {"/": 홈, "/안녕": 인사})   # http://localhost:8000
```
각 라우트 함수는 요청 사전 `{메서드, 경로, 질의, 본문, 쿠키}` 하나를 받아 문자열(→200 text/html) 또는 `{상태, 헤더, 본문[, 쿠키설정]}` 사전을 돌려줍니다. POST 폼(`application/x-www-form-urlencoded`) 으로 보낸 필드도 `요청["질의"]` 에 담겨 오므로 GET·POST 를 같은 방식으로 읽을 수 있어요(원본 본문은 `요청["본문"]` 에 그대로). 전체 예제: `examples/웹.ㄱㄴㄷ`(홈·질의 되돌리기·AI·쿠키 방문 횟수·SQLite 방명록 라우트).

**쿠키** — Cookie 헤더는 퍼센트 디코딩되어 `요청["쿠키"]` 사전(`{이름:값}`)으로 들어오고, 응답 사전에 `"쿠키설정": {이름:값}` 을 넣으면 각각 `Set-Cookie: 이름=값; Path=/; HttpOnly`(한글은 퍼센트 인코딩)로 나갑니다. 값 자리에 사전 `{"값": ..., "만료": 초}` 를 주면 `Max-Age=초` 가 붙어 지속 쿠키가 되고, `"만료": 0` 이면 브라우저가 그 쿠키를 지워 **로그아웃**이 됩니다(예: `{"세션": {"값": "", "만료": 0}}`). 예제: `examples/웹.ㄱㄴㄷ` 의 `/방문`. 서명은 아직 없어요(추후 과제).

**정적 서빙** — 셋째 인자로 폴더를 주면(`서버(8000, 라우트, "public")`) 라우트에 없는 경로는 그 폴더의 파일로 서빙합니다(확장자별 Content-Type, `/`→index.html, `../` 경로 이탈은 404 차단, 라우트가 우선). 예제: `examples/정적웹.ㄱㄴㄷ`.

**로컬 실행**
```bash
python3 가나다.py 실행 examples/웹.ㄱㄴㄷ
curl http://localhost:8000/
curl "http://localhost:8000/안녕?이름=철수"
```

**Docker 배포**
```bash
docker build -t ganada-web .        # 이미지 태그는 ASCII 만 허용
docker run -p 8000:8000 ganada-web
```
`Dockerfile` 은 `python:3.12-slim` 위에 `가나다.py` 와 앱 파일만 복사합니다. 서버가 `0.0.0.0:8000` 에 바인딩하므로 컨테이너 밖에서 바로 접근돼요. Docker 이미지를 받는 곳이면 어디든 배포 가능: **Fly.io · Railway · Render · 일반 VPS**.
