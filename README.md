# 한 (Han)

한글로 코딩하는 **독립 프로그래밍 언어**. AI 개발에 최적화하는 것을 목표로 한다.

> 파이썬으로 트랜스파일하지 않는다. 자체 문법 + 자체 렉서·파서·트리워킹 인터프리터(`han.py`)로 직접 실행한다.
> (구현 호스트가 파이썬일 뿐, 언어 자체는 독립적 — CPython이 C로 구현됐다고 파이썬이 C가 아니듯.)

## 실행
```bash
python3 han.py 실행 examples/hello.han   # 파일 실행
python3 han.py 대화                       # 대화형(REPL) — 여러 줄 블록 OK, 식은 값이 바로 나옴
python3 tests/test_han.py                 # 테스트
```

## 맛보기
```han
함수 피보나치(수) {
    만약 수 < 2 { 반환 수 }
    반환 피보나치(수 - 1) + 피보나치(수 - 2)
}
반복 i 를 0 부터 10 까지 {
    출력("피보나치(" + i + ") = " + 피보나치(i))
}
```

## 문법

**변수 / 복합 대입**
```han
이름 = "한"
합 = 0
합 += 5      # -= *= /= 도 됨 (변수·목록인덱스·문자열)
```

**함수 / 람다(익명 함수)**
```han
함수 더하기(가, 나) { 반환 가 + 나 }
제곱 = 람다(x) { 반환 x * x }     # 일급 함수 → 고차함수 가능
```

**조건**
```han
만약 점수 >= 90 { 출력("상") }
아니면 만약 점수 >= 70 { 출력("중") }
아니면 { 출력("하") }
```

**반복** (양끝 포함 범위 / 컬렉션 순회 / while), **멈춤·계속**
```han
반복 i 를 1 부터 5 까지 { 출력(i) }
반복 과일 를 ["사과", "배"] 에서 { 출력(과일) }
동안 수 > 0 { 수 -= 1 }
반복 i 를 1 부터 100 까지 {
    만약 i % 2 == 0 { 계속 }
    만약 i > 9 { 멈춤 }
}
```

**자료형**: 정수·실수·문자열·`참`/`거짓`/`없음`·목록 `[..]`·사전 `{키:값}`
```han
목록 = [1, 2, 3]
목록[0] = 9
사람 = {"이름": "한", "나이": 1}
사람["나이"] += 1
```

**모듈**
```han
가져오기 "lib.han"      # 다른 .han 파일의 함수·변수 사용
```

**연산**: `+ - * / %`, `== != < <= > >=`, `그리고`/`또는`/`아니다`
**주석**: `# ...`

## 내장 함수
- **출력·입력**: `출력(...)`, `입력([프롬프트])`, `숫자(문자열)`, `타입(값)`
- **목록**: `길이` `추가` `합` `정렬` `최대` `최소` `범위(끝|시작,끝)` `거꾸로` `고유` `개수(목록,값)` `묶기(목록1,목록2)` · 고차: `변환`(map) `거르기`(filter) `접기(목록,초기값,함수)`(reduce) `정렬기준(목록,키함수)` `찾기`(find) `있나`(any) `모두`(all)
- **문자열**: `대문자` `소문자` `다듬기` `바꾸기` `나누기` `합치기` `포함` `시작` `끝` `서식(틀,…값)`
- **사전**: `키들` `값들` `항목들`
- **JSON**: `제이슨파싱(문자열)` → 값 · `제이슨문자열(값[, 들여쓰기])` → JSON 문자열
- **수학**: `절댓값` `반올림(수[,자리])` `올림` `내림` `제곱근` `거듭제곱(밑,지수)`
- **무작위**: `무작위()`(0~1) `무작위정수(시작,끝)` `무작위선택(목록)`
- **AI**: `질문(프롬프트[, 모델])` · `체계질문(시스템, 사용자[, 모델])` — OpenRouter LLM 호출 (`OPENROUTER_API_KEY` 필요, 없으면 안내)

## 오류 메시지
- 구문/렉서 오류엔 **행+열** — 예: `[1행 7열] 구문 오류: 예기치 않은 ')'`
- 런타임 오류엔 행 번호 — 예: `[2행] 이름 오류: '없는변수' 가 정의되지 않았습니다`
